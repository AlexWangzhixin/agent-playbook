# 交付物 QA 清单

> 用途：交付前逐项过。
> 核心：**编译通过不等于交付。**

## 通用（所有交付物）

- [ ] 结论先行；一段能说清的不分十段
- [ ] 路径明确，文件真实存在
- [ ] 关键数字独立重算，带来源
- [ ] 已验证 / 未验证 / 待确认分开表述
- [ ] 没有把团队成果写成个人成果、把计划写成已完成
- [ ] 术语、编号、引用、作者自填字段保留原样

## Markdown（默认格式）

- [ ] UTF-8 编码，无乱码
- [ ] 标题层级连续，无跳级
- [ ] 相对链接/图片可点开；图片路径真实存在
- [ ] 代码块有语言标注；表格格式正确
- [ ] **无占位符残留**：`TODO` / `TBD` / `xxx` / `待填` / 空 `【】`
- [ ] 命令行里没有把凭据或本地绝对路径写死

## DOCX

- [ ] **真实渲染**并**逐页**检查（不是只导出成功）
- [ ] 页数符合预期；无字段在打印版被截断
- [ ] 公式、字体、表格边框正常
- [ ] 修订/批注/保护状态符合要求
- [ ] 非 ASCII 内容先设 `PYTHONIOENCODING=utf-8`
- [ ] renderer 的 GBK 警告**既不是失败证明也不是成功证明**，要看 PDF 和页图是否真的生成

## PDF

- [ ] 页数与页面尺寸（A4 = 595.304 x 841.89 pts）
- [ ] 每页渲染成图后目视检查
- [ ] 表格/公式/手写/多栏布局依赖视觉核验，不能只抽文本
- [ ] 引用、数字、日期、公式、单位与渲染页逐一对照
- [ ] 缺 PDF Python 模块时用 `pdftotext -layout` / `pdfinfo` / `pdftoppm`

## PPTX

- [ ] 结构检查：幻灯片数 = 备注数（若要求每页有备注）
- [ ] 无禁用词残留（按当时要求列黑名单）
- [ ] 截图值 / 已核实事实 / 待确认字段三者分开
- [ ] 源文件哈希未变（若要求不动原件）

## XLSX

- [ ] 导出 PDF 核对页数与 A4；检查字段是否在打印版截断
- [ ] 公式算过（不只打开成功）；关键格子独立复算
- [ ] 无虚构值；缺材料时保留模板空白，不补造

## 涉及"可打印/可提交"的正式材料

- [ ] 只保留明确标注要的页面，不额外保留或改版未标注页
- [ ] 照片栏等无材料处**保留空白**，不虚构
- [ ] 打印版逐页看，字段不截断

## 最后一项

- [ ] 把 QA 结果写进项目的 `STATUS.md` 或 `qa.json`，**不要只在对话里说"我查过了"**
